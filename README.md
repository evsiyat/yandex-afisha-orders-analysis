**Анализ данных заказов**
Учебный проект по анализу данных заказов. В рамках проекта проведены исследовательский анализ данных, анализ с помощью SQL и визуализация ключевых показателей в Yandex DataLens.

**Цель проекта**
Проанализировать данные о заказах, изучить основные показатели и выявить закономерности, которые могут быть полезны для оценки продаж и выручки.

**Инструменты**
- Python
- Jupyter Notebook
- Pandas
- Matplotlib / Seaborn
- SQL
- DBeaver
- Yandex DataLens
  
**Этапы проекта**
1. Исследовательский анализ данных

Проведена загрузка и подготовка данных, исследованы основные характеристики датасета, распределения показателей и выявлены основные закономерности.

2. Анализ данных с помощью SQL

С помощью SQL проведен анализ заказов и рассчитаны основные показатели.


3. Дашборд

На основе результатов анализа создан интерактивный дашборд в Yandex DataLens.

**Результаты**

В ходе проекта были изучены основные показатели заказов и выручки, проведен анализ данных с использованием Python и SQL, а результаты представлены в виде интерактивного дашборда.
